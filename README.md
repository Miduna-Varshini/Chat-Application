# Real-Time Chat Application

A simple real-time chat application built using React.js and Go WebSockets.  
Users can join the chat and send messages instantly in real time.

## Tech Stack

- React.js
- Go (Golang)
- WebSockets

## Features

- Real-time messaging
- Multiple users chat

## Live Demo

Frontend: [Live Demo](https://chat-application-six-mocha.vercel.app/)

## Run Locally

### Frontend

```bash
cd Frontend/chat-ui
npm install
npm run dev
```

### Backend

```bash
cd Backend
go run main.go
```
